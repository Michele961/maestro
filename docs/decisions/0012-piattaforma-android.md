# ADR-0012 — Android nativo, API minima 26

Stato: accettato · 2026-10-23

## Decisione
App nativa Android in Kotlin + Jetpack Compose, una sola Activity, architettura MVI. `minSdk = 26`. iOS arriverà in Fase 4 tramite Compose Multiplatform.

## Conseguenze
Nessun modulo Android prima della Fase 1.
