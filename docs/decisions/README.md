# Decisioni architetturali (ADR)

Ogni ADR registra una decisione presa, il contesto e le conseguenze. Gli ADR **accettati** non si riaprono senza Michele.

Per proporre una decisione nuova: un agente scrive la proposta nella PR ("Domande aperte"); se Michele approva, si crea `NNNN-titolo.md` con stato `accettato`.
